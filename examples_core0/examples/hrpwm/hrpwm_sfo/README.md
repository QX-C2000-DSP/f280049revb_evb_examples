## 使用说明
- 本例展示了如何使用hrpwm模块，并调用sfo函数来对mep值进行校准。
- 控制pwm1输出占空比可调的hrpwm波,pwm的频率为1Mhz，通过改变dutyFine的值来调整pwm的占空比

### 外部连接：
- GPIO0 hrPWM1A
- GPIO1 hrPWM1B
