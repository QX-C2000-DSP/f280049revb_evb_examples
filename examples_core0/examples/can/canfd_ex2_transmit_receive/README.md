#### 使用说明
* 本例展示了如何使用canfd模块进行数据的收发，仲裁域波特率为500k，数据域波特率为2M.
* 如果定义了TRANSMIT则CANFDB向can盒发送扩展数据帧，帧ID为0x12131415
* 如果未定义TRANSMIT则使能接收中断，可通过can盒向芯片发送帧ID为0x121314x5的扩展数据帧，接收到的数据存储在rxMsgData中
* 可通过TXCOUNT配置要发送的数据帧的数量
* 如果发送和接收过程中有任何通信错误，错误标志位errorFlag会置起
* 需要一个CAN收发器将芯片连接到can盒进行通信，CANFDB_RX: IO7, CANFDB_TX: IO6
