#### 使用说明
* 本例展示了如何进行canfd模块外部回环模式测试，波特率1M。CANFDB模块通过收发器进行数据的自收发。
* 需要一个CAN收发器，CANFDB_RX: IO7, CANFDB_TX: IO6
* 本例程可用于测试收发器以及CAN线路连接是否正常，若出现异常，则errorFlag会置1，正常情况下msgCount每0.5s会递增一次。
