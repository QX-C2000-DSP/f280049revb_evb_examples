#### 使用说明
* 本例展示了如何使用canfd模块进行数据的收发，仲裁域波特率为500k，数据域波特率为2M.
* CANFDA发送数据，CANFDB通过接收中断接收数据
* 可通过TXCOUNT配置要发送的数据帧的数量
* 如果发送和接收到的数据不一致，错误标志位errorFlag会置起
* 如果测试完成且没有错误，测试完成标志位canTestFinishFlag会置起
* 需要两个CAN收发器将两个CANFD模块连接，CANFDA_RX: IO30, CANFDA_TX: IO31, CANFDB_RX: IO7, CANFDB_TX: IO6
