## 使用说明
- 本例展示了如何使用eCAP模块的捕获功能。
- 控制EPWM3输出频率变化的PWM波形，使用ecap1,ecap2和ecap3同步采集EPWM3的输出波形，在ecap3的中断中校验三个cap采集的值是否相等
- 若出现偏差，则置位errorFlag
### 外部连接：
- GPIO4配置为EPWM_A的输出，GPIO16配置为ecap1,ecap2和ecap3的输入，将GPIO4和GPIO16相连接
