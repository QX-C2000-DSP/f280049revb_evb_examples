## 使用说明
- 本例展示了如何使用eCAP模块的APWM功能。
- 控制eCAP模块的APWM输出一个占空比在5hz和10hz之间不断变化，占空比恒定为50%的一个PWM波
- eCAP的APWM的输出通过OUTPUTXBAR3连接到GPIO完成输出

### 外部连接：
- GPIO5为eCAP的APWM的输出
