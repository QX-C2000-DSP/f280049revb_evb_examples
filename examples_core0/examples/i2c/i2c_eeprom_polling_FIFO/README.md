#### 使用说明
* 本例展示了如何配置I2C主机轮询 + 结合FIFO模式, 驱动外设 EEPROM (AT24C02).
* 通过 i2c_bus_id_e 枚举的 I2C_BUS_x 初始化 I2C_gpioInit(I2C_BUS_x) 绑定的一组i2c gpio,
* 通过 I2C_init() 函数传入需要设置的通信速率, 目前最大支持400Kbps,
* 
* 通过下面宏定义去设置EEPROM型号的1页page size 以及最大内存地址, 本案例以 AT24C02 为例:
*   #define EEPROM_PAGE_SIZE    8
*   #define EEPROM_MEMORY_SIZE  0x100
* 
* 应用层思路:
*   write 一组数据, 间隔6ms后再 read 数据出来, 最后对写、读数据是否相同做校验, 
*   如果检验读写数据存在不一致, 串口(SCIB GPIO12) 会以 921600 波特率打印出错项.
* 
* 备注: 一次读写数据的个数可通过 MAX_WTRD_SIZE 宏定义根据需要修改, 注意最好不要超过 1 page size.
* 

#### 硬件

*  I2CA -
*   GPIO0/SDA
*   GPIO1/SCL
* 
* 串口(波特率 = 921600):
*   SCIB GPIO12
