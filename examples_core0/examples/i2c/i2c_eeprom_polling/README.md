#### 使用说明
* 本例展示了如何配置I2C主机轮询模式, 驱动外设 EEPROM (AT24C128).
* 通过 i2c_bus_id_e 枚举的 I2C_BUS_x 初始化 i2c_gpio_init(I2C_BUS_x) 绑定的一组i2c gpio,
* 通过 i2c_init() 函数传入需要设置的通信速率, 最大支持400Kbps,
* 
* 应用层思路:
*   write 一组数据, 间隔5ms后再 read 数据出来, 最后对写、读数据是否相同做校验, 
* 

#### 硬件
* I2CA 引脚定义：
*   GPIO0/SDA
*   GPIO1/SCL
