#### 使用说明
- 本例展示了如何配置SCI串口结合DMA发送和接收数据，DSP首先会打印欢迎信息，然后会返回串口助手发来的数据。
- 串口助手发数据时需保证一定的协议格式，第一个字节代表着帧的长度，后面跟着帧的内容
- 配置DMA1用来发送数据，DMA2用来接收数据，开启了DMA2的传输完成中断
- 首先配置DMA2的transfer大小为1，也就是接收一个字节进入DMA2的中断状态机RECV_STATUS_IDLE，在这个状态机中将DMA2的transfer大小配置为帧的长度
- 然后帧传输完成之后，进入DMA2的中断状态机RECV_STATUS_RECV_DATA，处理接收的数据，并将数据使用DMA1回传给串口助手

### 外部连接：
- 插上电源线，串口助手设置正确的端口号即可
