#### 使用说明
- 本例展示了如何配置SCI串口结合DMA发送数据，FIFO中断接收数据，DSP首先会打印欢迎信息，然后会返回串口助手发来的数据。
- 配置DMA1用来发送数据，启用FIFO中断接收数据
- 注意串口发送的数据需保证以'\n'来结尾

### 外部连接：
- 插上电源线，串口助手设置正确的端口号即可
