## 使用说明
- 本例展示了如何使用sci模块
- 控制SCI和pc端串口助手通信，DSP打印欢迎信息，并将串口助手发来的数据返回，波特率921600
- 此例程开启了SCI的发送和接收FIFO中断

### 外部连接：
- 插上电源线，串口助手设置正确的端口号即可
