## 使用说明
- 本例展示了如何使用hrcap 测量信号占空比和周期。
- 将外部晶振的8分频输出绑定到GPIO16
- GPIO2为hrcap的输入
- 将GPIO16和GPIO2相连接
- 调试器观测全局变量，period1、period2为测量的信号周期，offTime1，offTime2为测量信号的高电平时间，onTime1，onTime2为信号的低电平时间
- 测量结果单位均为ns
