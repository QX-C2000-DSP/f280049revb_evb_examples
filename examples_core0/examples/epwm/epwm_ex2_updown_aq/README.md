# epwm_ex2_updown_aq.c

## 文件所有
本文适用于QXS320F28XXX系列芯片的ePWM 动态调整占空比的示例例程。

## 使用说明
- 本例展示了如何动态调整ePWM的占空比。
- 本例通过每三个PWM周期触发一次ePWM中断，在中断中动态调整AQ子模块的比较值来实现动态调整占空比。


### 外部连接：
- GPIO0为ePWM1_A的输出，GPIO1为ePWM1_B的输出，GPIO2为ePWM2_A的输出，GPIO3为ePWM2_B的输出，GPIO4为ePWM3_A的输出，GPIO5为ePWM3_B的输出
