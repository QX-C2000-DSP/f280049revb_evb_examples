## 使用说明
- 本例展示了如何使用ePWM模块的PC子模块。
- EPWM1为参考信号，EPWM1未进行任何斩波配置，在测试中可以以EPWM1作为参考对比

- 控制EPWM2的斩波子模块输出单脉冲宽度为80ns,脉冲占空比为12.5%的脉冲波形
- 控制EPWM3的斩波子模块输出单脉冲宽度为80ns,脉冲占空比为75%的脉冲波形
- 控制EPWM4的斩波子模块输出单脉冲宽度为880ns,脉冲占空比为50%的脉冲波形

### 外部连接：
- GPIO0 EPWM1A
- GPIO1 EPWM1B
- GPIO2 EPWM2A
- GPIO3 EPWM2B
- GPIO4 EPWM3A
- GPIO5 EPWM3B
- GPIO6 EPWM4A
- GPIO7 EPWM4B
