# epwm_ex12_monoshot_mode.c

## 文件所有

## 使用说明
- 本例中epwm2为触发源，epwm2输出频率为100KHZ，占空比为1%的脉冲触发信号，该信号通过X-BAR input5馈送到EXTSYNCIN1作为epwm1的同步输入
- epwm1接受到此触发信号后输出一个0.5us的单脉冲波形

### 外部连接：
- GPIO0 EPWM1A
- GPIO2 EPWM2A
