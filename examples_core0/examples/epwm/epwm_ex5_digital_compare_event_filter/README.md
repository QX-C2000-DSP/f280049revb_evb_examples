# epwm_ex5_digital_compare_event_filter.c

## 文件所有
本文适用于QXS320F28XXX系列芯片的ePWM DC子模块生成数字比较事件来触发跳闸，并对事件进行空窗滤波的示例例程。

## 使用说明
- 本例程配置GPIO25通过XBAR INPUT1路由到TZ1
- 通过配置DCTRIPSEL寄存器将TZ1馈送到DCAH和DCBH
- 通过配置TZDCSEL寄存器配置当DCAH低，DCAL任意时，产生数字比较A事件1，当DCBH低，DCBL任意时，产生数字比较B事件1
- 设置TZ子模块当接收到DCAEVT1或DCBEVT1事件时，控制pwm强制输出低
- 并配置DCBEVT1事件经过空窗滤波模块，滤波窗口长度为6000TBCLK

### 外部连接：
- GPIO0为ePWM1_A的输出，GPIO1为ePWM1_B的输出，GPIO25为触发跳闸的信号来源
