## 使用说明
- 本例展示了如何使用DMA来更新EPWM的比较值，相移值和周期值。
- DMA1来更新比较寄存器的值，DMA2来更新相移寄存器和周期寄存器的值，每个PWM周期都会更新一次
- phasePeriodConfigs和compareConfigs为每个PWM周期要更新的值
- DMA使用链表来实现值的循环不断更新，一次DMA触发搬运四个值，搬运四个之后跳到下一个链表，目标地址回绕，源地址指到下一组


### 外部连接：
- GPIO0 EPWM1A
- GPIO1 EPWM1B
