  #### 使用说明

  * 本例展示了低功耗HLAT模式的进入和退出，HLAT模式的退出通过将GPIO8拉低实现
  * 正确的接入打印串口，芯片正常运行时如果一直将GPIO8拉低将在打印串口上看到每秒打印一次如下输出：

  ```shell
  halt mode enter
  wakeISR
  halt mode leave
  ```
