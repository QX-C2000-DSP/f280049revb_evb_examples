## 使用说明
- 本例展示了如何使用ePWM模块的TZ子模块。
- GPIO12通过XBAR_INPUT1连接到TZ1作为ePWM的跳闸事件。
- 跳闸事件产生后EPWM1_A和EPWM2_A强制输出高电平
- EPWM1_A设定为单次触发，EPWM2_A设定为逐周期触发
- 在epwm2TZISR中断中会翻转GPIO11

### 外部连接：
- GPIO0为EPWM1_A的输出，GPIO2为EPWM2_A的输出，GPIO12为跳闸事件接口，拉低GPIO12会触发跳闸
