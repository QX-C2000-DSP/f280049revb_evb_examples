## 使用说明
- 本例展示了如何使用PGA模块
- 控制内部DAC采用内部参考1.65v，2倍增益，输出400mv，并经过PGA进行三倍放大
- ADC的SOC0转换测量DAC的输出，SOC1转换测量PGA的输出
- dacResult为DAC的输出测量结果
- pgaResult为PGA的输出测量结果
- pgaGain为PGA增益放大倍数

### 外部连接：
- 将DAC的输出A0和PGA的输入PGA2_IN相连接
