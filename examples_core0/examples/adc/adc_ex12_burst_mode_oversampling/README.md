# ADC突发模式过采样示例

## 文件说明
本文适用于通过软件实现ADC过采样的示例例程，展示如何使用突发模式结合ePWM触发实现过采样。

## 使用说明
- 本例通过软件实现ADC的过采样。
- ADC的SOC（Start of Conversion）被配置为突发模式，并由ePWM的SOC A事件触发。
- 过采样量由变量`Oversampling_Amount`定义。

### 外部连接：
- A2引脚应连接到需要转换的信号。

### 观察变量：
- `lv_results` - 一个存储A2引脚电压测量值的数组，包含过采样后的数字值。

## 硬件
- **ADC引脚定义：**
  - A2: 连接至模拟信号源。

## 如何运行
1. **连接引脚：**
   - 将A2引脚连接到对应的模拟信号源。

2. **配置和编译：**
   - 打开开发环境QX-IDE并配置项目。
   - 编译项目并烧录到目标设备。

3. **运行和验证：**
   - 运行程序，观察`lv_results`数组中的测量值，根据`Oversampling_Amount`验证过采样效果。

## 注意事项
- 确保模拟信号源已正确连接到A2引脚。
- 根据应用需求调整`Oversampling_Amount`变量，改变过采样的数量。
