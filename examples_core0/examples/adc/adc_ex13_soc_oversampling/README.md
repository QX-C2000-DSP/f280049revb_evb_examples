# ADC SOC过采样示例

## 文件说明
本文适用于通过多次SOC（Start of Conversion）实现ADC过采样的示例例程，展示如何配置ePWM定期触发多次SOC以对同一信号通道进行过采样。

## 使用说明
- 本例配置ePWM1定期触发ADCA的一组SOC，将对A2通道进行多次转换以实现过采样。
- ADCA中断ISR被用于读取转换结果。

### 外部连接：
- A0、A1、A2引脚应连接到需要转换的信号。

### 观察变量：
- `adcAResult0` - A0引脚电压的数字表示。
- `adcAResult1` - A1引脚电压的数字表示。
- `adcAResult2` - A2引脚电压的数字表示。

## 硬件
- **ADC引脚定义：**
  - A0: 连接至模拟信号源。
  - A1: 连接至模拟信号源。
  - A2: 连接至模拟信号源。

## 如何运行
1. **连接引脚：**
   - 将A0、A1和A2引脚连接到对应的模拟信号源。

2. **配置和编译：**
   - 打开开发环境QX-IDE并配置项目。
   - 编译项目并烧录到目标设备。

3. **运行和验证：**
   - 运行程序，观察`adcAResult0`、`adcAResult1`和`adcAResult2`变量中的转换结果，验证过采样效果。

## 注意事项
- 确保模拟信号源已正确连接到A0、A1和A2引脚。
- ePWM的触发周期和SOC的数量可以根据应用需求调整，以满足不同的过采样需求。
