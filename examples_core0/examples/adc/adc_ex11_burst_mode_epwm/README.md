# ADC突发模式示例

## 文件说明
本文适用于使用ePWM触发ADC突发模式的示例例程，展示如何通过突发模式对不同通道进行采样，并以较高效率同时处理高优先级和低优先级信号。

## 使用说明
- 本例展示了如何配置ePWM1周期性触发ADCA进入突发模式进行采样。
- 每次突发会触发3次转换：
  - A0和A1为固定采样通道。
  - 第三个采样通道在A2、A3和A4之间轮换。
- 高优先级信号（A0和A1）以较高速度采样，低优先级信号（A2、A3和A4）以较低速率采样。

### 外部连接：
- A0、A1、A2、A3和A4引脚应连接到需要转换的信号。

### 观察变量：
- `adcAResult0` - A0引脚电压的数字表示。
- `adcAResult1` - A1引脚电压的数字表示。
- `adcAResult2` - A2引脚电压的数字表示。
- `adcAResult3` - A3引脚电压的数字表示。
- `adcAResult4` - A4引脚电压的数字表示。

## 硬件
- **ADC引脚定义：**
  - A0: 连接至模拟信号源。
  - A1: 连接至模拟信号源。
  - A2: 连接至模拟信号源。
  - A3: 连接至模拟信号源。
  - A4: 连接至模拟信号源。

## 如何运行
1. **连接引脚：**
   - 将A0、A1、A2、A3和A4引脚连接到对应的模拟信号源。

2. **配置和编译：**
   - 打开开发环境QX-IDE并配置项目。
   - 编译项目并烧录到目标设备。

3. **运行和验证：**
   - 运行程序，观察`adcAResult0`、`adcAResult1`、`adcAResult2`、`adcAResult3`和`adcAResult4`变量中的转换结果，验证突发模式的运行效果。

## 注意事项
- 确保所有模拟信号源已正确连接到对应的ADC引脚。
- ePWM的触发周期可以根据应用需求调整。
