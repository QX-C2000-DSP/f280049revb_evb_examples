# ADC多SOC ePWM触发

## 文件说明
本文适用于使用ePWM触发多个SOC（Start of Conversion）进行ADC转换的示例例程，展示了多个ADC协同工作的能力，通过利用多个ADC的并行性高效处理一组转换任务。

## 使用说明
- 本例展示了如何通过ePWM1周期性触发ADCA和ADCC执行一组转换任务。
- 使用ADCA的中断服务程序（ISR）读取ADCA和ADCC的转换结果。

### 外部连接：
- A0、A1、A2和C2、C3、C4引脚应连接到需要转换的信号。

### 观察变量：
- `adcAResult0` - A0引脚电压的数字表示。
- `adcAResult1` - A1引脚电压的数字表示。
- `adcAResult2` - A2引脚电压的数字表示。
- `adcCResult0` - C2引脚电压的数字表示。
- `adcCResult1` - C3引脚电压的数字表示。
- `adcCResult2` - C4引脚电压的数字表示。

## 硬件
- **ADC引脚定义：**
  - A0: 连接至模拟信号源。
  - A1: 连接至模拟信号源。
  - A2: 连接至模拟信号源。
  - C2: 连接至模拟信号源。
  - C3: 连接至模拟信号源。
  - C4: 连接至模拟信号源。

## 如何运行
1. **连接引脚：**
   - 将A0、A1、A2和C2、C3、C4引脚连接到对应的模拟信号源。

2. **配置和编译：**
   - 打开开发环境QX-IDE并配置项目。
   - 编译项目并烧录到目标设备。

3. **运行和验证：**
   - 运行程序，观察`adcAResult0`、`adcAResult1`、`adcAResult2`、`adcCResult0`、`adcCResult1`和`adcCResult2`变量中的转换结果，验证多个ADC协同工作的效果。

## 注意事项
- 确保所有模拟信号源已正确连接到对应的ADC引脚。
- ePWM的触发周期可以根据应用需求调整。
