## 使用说明
- 本例展示了如何使用软件触发进行ADCA和ADCC的电压转换。
- 配置ADCA的S0C0对A0进行转换，ADCC的S0C0对C2进行转换
- 因此ADCA.ADCRESULT0中存储的是A0&A1的结果，因此ADCC.ADCRESULT0中存储的是C2&C3的结果
  
### 外部连接：
- A0、A1、C2 和 C3 应连接到需要转换的信号。

### 观察变量：
- `myADC0Result0` - A0和A1引脚电压差的数字表示。
- `myADC1Result0` - C2和C3引脚电压差的数字表示。
