# ADC连续自触发

## 文件说明
本文适用于ADC连续自触发示例例程，展示如何设置ADC进行连续转换，以实现最大采样率。

## 使用说明
- 本例展示了如何将ADC设置为连续转换模式，以实现最大采样率。
  
### 外部连接：
- A0引脚应连接到需要转换的信号。

### 观察变量：
- `adcAResults` - 从A0引脚获取的一系列模拟到数字的转换结果。转换结果之间的时间是基于ADC速度的最小时间间隔。

## 硬件
- **ADC引脚定义：**
  - A0: 连接至模拟信号源

## 如何运行
1. **连接引脚：**
   - 将A0引脚连接到模拟信号源，以便进行ADC转换。

2. **配置和编译：**
   - 打开开发环境QX-IDE并配置项目。
   - 编译项目并烧录到目标设备。

3. **观察输出：**
   - 运行程序并查看连续转换的结果，`adcAResults`变量表示A0引脚的数字转换结果序列。

## 注意事项
- 本示例演示了ADC连续自触发模式，适用于需要最大采样率的应用。
- 确保模拟信号源已正确连接到A0引脚。
