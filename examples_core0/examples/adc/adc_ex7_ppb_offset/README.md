## 使用说明
- 本例演示了如何使用软件触发ADC并通过后处理块（PPB）调整ADC的偏移量。
- 一些SOC芯片具有自动偏移调整功能，后处理块可以自动应用偏移调整。
- 程序运行后，内存中将包含ADC和后处理块（PPB）结果。

### 外部连接：
- A2、C2引脚应连接到需要转换的信号源。

### 观察变量：
- `myADC0Result` - A2引脚电压的数字表示。
- `myADC0PPBResult` - A2引脚电压减去100 LSB（最小有效位）的自动偏移后的数字表示。
- `myADC1Result` - C2引脚电压的数字表示。
- `myADC1PPBResult` - C2引脚电压加上100 LSB（最小有效位）的自动偏移后的数字表示。

## 硬件
- **ADC引脚定义：**
  - A2: 连接至模拟信号源。
  - C2: 连接至模拟信号源。

## 如何运行
1. **连接引脚：**
   - 将A2、C2引脚连接到模拟信号源。

2. **配置和编译：**
   - 打开开发环境QX-IDE并配置项目。
   - 编译项目并烧录到目标设备。

3. **观察输出：**
   - 运行程序并查看转换结果：
     - `myADC0Result` 和 `myADC1Result` 显示原始的ADC采样值。
     - `myADC0PPBResult` 和 `myADC1PPBResult` 显示经过后处理块（PPB）调整的ADC值。

## 注意事项
- 本示例使用后处理块（PPB）自动应用偏移调整，确保偏移的值可以根据应用需求进行正确调整。
- 根据芯片型号和外部连接，可能需要调整PPB的偏移值。
