# ADC后处理模块（PPB）限值检查

## 文件说明
本文适用于使用ADC后处理模块（PPB）进行限值检查的示例例程，展示如何通过设置ePWM定期触发ADC并在采样结果超出指定范围时生成中断。

## 使用说明
- 本例展示了如何配置ePWM定期触发ADC转换，并使用后处理模块（PPB）根据设定的限值范围进行检查。
- 默认限值为 1000 LSBs 和 3000 LSBs。在VREFHI为3.3V时，当输入电压高于约2.4V或低于约0.8V时，PPB将生成中断。
- LSB,即最低有效位。ADC数字输出中最小可分辨单位，本例中，1LSB = 3.3V / 4095 = 0.0008
### 外部连接：
- A0引脚应连接到需要转换的信号。

### 观察变量：
- 无。

## 硬件
- **ADC引脚定义：**
  - A0: 连接至模拟信号源

## 如何运行
1. **连接引脚：**
   - 将A0引脚连接到模拟信号源，以便进行ADC转换。

2. **配置和编译：**
   - 打开开发环境QX-IDE并配置项目。
   - 编译项目并烧录到目标设备。

3. **运行和验证：**
   - 运行程序，观察系统在输入电压超出指定范围（低于约0.8V或高于约2.4V）时是否生成中断。

## 注意事项
- 本示例使用的限值为默认值（1000 LSBs 和 3000 LSBs），可根据需要调整。
- 确保模拟信号源已正确连接到A0引脚。
