# ADC后处理模块（PPB）延迟捕获

## 文件说明
本文适用于使用ADC后处理模块（PPB）实现延迟捕获的示例例程，展示如何通过设置异步触发器捕获转换延迟信息。

## 使用说明
- 本例展示了如何使用后处理模块（PPB）捕获ADC采样的延迟信息。
- 配置两个异步ADC触发器：
  - ePWM1，周期为2048，触发SOC0在A0引脚进行转换。
  - ePWM2，周期为9999，触发SOC1在A2引脚进行转换。

- 每次转换结束后会生成中断：
  - 在SOC0的中断服务程序中，递增转换计数器并检查PPB是否检测到采样延迟。

### 外部连接：
- A0和A2引脚应分别连接到需要转换的信号。

### 观察变量：
- `conversion` - SOC0延迟转换的序列。
- `delay` - 每次延迟转换对应的延迟时间。

## 硬件
- **ADC引脚定义：**
  - A0: 连接至模拟信号源。
  - A2: 连接至模拟信号源。

## 如何运行
1. **连接引脚：**
   - 将A0和A2引脚分别连接到对应的模拟信号源，以便进行ADC转换。

2. **配置和编译：**
   - 打开开发环境QX-IDE并配置项目。
   - 编译项目并烧录到目标设备。

3. **运行和验证：**
   - 运行程序，观察内存中的`conversion`序列及其对应的`delay`值，验证延迟转换的捕获效果。

## 注意事项
- ePWM1和ePWM2触发器周期值可根据需求调整。
- 确保A0和A2引脚的模拟信号源已正确连接并能正常工作。
