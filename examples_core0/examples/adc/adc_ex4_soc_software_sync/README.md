# ADC同步软件触发

## 文件说明
本文适用于使用软件触发同步ADC转换的示例例程，展示如何通过输入X-BAR的输入5和GPIO0引脚实现ADCA和ADCC的同步转换。

## 使用说明
- 本例展示了如何通过软件触发方式同步进行ADCA和ADCC的电压转换。
- 输入X-BAR的输入5由GPIO0的切换触发，但也可以使用其他空闲GPIO引脚。通过这种方法，可以确保两个ADC在相同的时刻开始转换。

### 外部连接：
- A2、A3、C2 和 C3 应连接到需要转换的信号。

### 观察变量：
- `myADC0Result0` - A2引脚电压的数字表示。
- `myADC0Result1` - A3引脚电压的数字表示。
- `myADC1Result0` - C2引脚电压的数字表示。
- `myADC1Result1` - C3引脚电压的数字表示。

## 硬件
- **ADC引脚定义：**
  - A2: 连接至模拟信号源
  - A3: 连接至模拟信号源
  - C2: 连接至模拟信号源
  - C3: 连接至模拟信号源

## 如何运行
1. **连接引脚：**
   - 将A2、A3、C2 和 C3引脚连接到对应的模拟信号源，以便进行ADC转换。

2. **配置和编译：**
   - 打开开发环境QX-IDE并配置项目。
   - 编译项目并烧录到目标设备。

3. **观察输出：**
   - 运行程序并查看转换结果，`myADC0Result0`、`myADC0Result1`、`myADC1Result0` 和 `myADC1Result1` 表示各引脚的电压值。

## 注意事项
- 本示例演示了同步软件触发模式，若需更高效的ADC转换，建议使用硬件触发方式。
- 确保模拟信号源已正确连接到ADCA和ADCC引脚。
