## 使用说明
- 本例展示了如何配置内部晶振通过GPIO16八分频输出
- 此用例可以用来测量对应时钟的频率
- 通过此函数SysCtl_selectClockOutSource(SYSCTL_CLOCKOUT_INTOSC1);可配置需要输出的时钟类型
- SysCtl_setXClk(SYSCTL_XCLKOUT_DIV_8);配置时钟输出的分频比例

### 外部连接：
- GPIO16连接示波器观察时钟输出
