#### 使用说明
- 本例使用SPI结合DMA完成spi自收发回环
- DMA1用于spi的发送，DMA2用于spi的接收
- DMA配置为突发模式，一次DMA触发搬运8笔数据
- 并开启dma传输完成中断，传输完成之后校验数据，数据校验不通过，error_flag置1
