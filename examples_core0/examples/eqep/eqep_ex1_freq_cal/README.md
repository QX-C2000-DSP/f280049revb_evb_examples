## 使用说明
- 本例展示了使用EQEP模块测量输入信号的频率
- 配置ePWM1A产生一个5kHz的波形来模拟编码器QEPA的一个输出
- freq.freqHzFR为定时测角法（M法）测量的结果
- freq.freqHzPR为定角测时法（T法）测量的结果

### 外部连接：
- GPIO0为EPWM1_A的输出，GPIO10为EQEPA的输入，将GPIO0和GPIO10连接
