#### 使用说明
- 本例展示了如何对片上flash进行擦除，写入和读取
- 本例对片上flash全片进行了测试，测试结果通过串口打印输出，测试通过将打印flash test pass!
- 测试不通过将打印相关错误信息，并且开发板上LED闪烁提示
- 测试流程为先执行擦除指令，读取数据并校验是否为0xFFFFFFFF，然后写入相关数据，再次进行读取校验，最后再执行一遍擦除指令
