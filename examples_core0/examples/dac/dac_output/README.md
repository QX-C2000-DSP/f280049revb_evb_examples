#### 使用说明
* 本例展示了如何配置 DACA. (注意: VREF使用外部参考源)
* 
* DACA 绑定模拟IO - GPIOA0 每间隔1s轮询输出 1V、2V、3V 电压.
* 

#### 硬件
* DACA 引脚定义：DACA-GPIOA0
* 
* 注意：VREF需要跳线帽短接到3.3V
