#### 使用说明
* 本例展示了如何配置SPI主机轮询模式, 驱动外设ADS1120/ADS1220, 输出电压至 DAC.
* 可通过配置 ads1220.h 头文件中的 "#define ADS1120" 宏定义来选择驱动 ADS1120.
* 
* 芯片DAC引脚绑定GPIO-A0，参考外部电压Vref = 3.3V，输出码值从0~0xFFF(4095)，输出电压范围从0~3.3V.
* 通过设置外设ADS1120的寄存器来选择模拟通道AIN0，连接至芯片GPIO-A0对芯片DAC输出的电压进行ADC采样.
* 芯片SPI读取ADS1120采样转换完成的码值，打印显示原始数据和转换后的采样电压值.
* 
* ADS_task 处理逻辑:
* 按周期读取ADS1120数据，连续读取9次，舍弃前4次数据，从第data[4]累加5次后取平均值，计算转换后的采样电压值.
* 

#### 硬件
* SPI_B 引脚定义：
*   MISO: GPIO_6
*   MOSI: GPIO_7
*   CLK : GPIO_26
*   CS  ：GPIO_15
* 
* DAC_A 引脚定义：
*   GPIO_A0
* 
* DRDY:
*   GPIO_0
