#### 使用说明
* 本例展示了如何配置 DCSM的EXEONLYSECT的应用:
* 通过下面寄存器控制exeonlysect，只执行寄存器，即使解锁了也仍然不可访问.
* DCSM_setConfig(B0Z1_exeonlysect,0xFFFFFFFE);
* B0Z1_exeonlysect，对此寄存器的编程为一次性编程;
* 对于DCSM模块的不当操作可能锁死芯片，因此建议您在工程开发的末尾阶段再进行DCSM模块的相关设置和操作。
