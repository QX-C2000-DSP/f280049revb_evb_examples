#### 使用说明
* 本例展示了如何配置 寄存器 控制到 DCSM 模块的应用:
* 本例只将flash第一块内存配置为Zone1，地址范围如下：
* define BANK0_SEG0_START  32'h3000_0000；
* define BANK0_SEG0_END    32'h3000_FFFF；
* 通过下面寄存器控制B0Z1的flash分区的第一块内存进行加密：
* DCSM_setConfig(B0Z1_grabsect,0xFFFFFFFD);
* 通过B0Z1_csmpswd0~4和B0Z1_csmkey0~4进行加密码和解密码具体值的设置；
* B0Z1_grabsect对此寄存器的编程为一次性编程，修改link以重新操作，B0Z1_csmkey0~4此寄存器允许被反复写入；
* 对于DCSM模块的不当操作可能锁死芯片，因此建议您在工程开发的末尾阶段再进行DCSM模块的相关设置和操作。
