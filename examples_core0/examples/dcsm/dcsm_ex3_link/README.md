#### 使用说明
* 本例展示了如何配置 寄存器 控制到 DCSM Link模块的应用:
* 加密部分可参考其他示例例程；
* 通过控制寄存器B0Z1_link1~3，操作此寄存器可以对B0Z1进行重新配置，包括配置B0Z1的FLASH区域以及密码等；
* 对link寄存器只能把每一位从1置0，无法反向操作，对此寄存器的编程为一次性编程；
* 对于DCSM模块的不当操作可能锁死芯片，因此建议您在工程开发的末尾阶段再进行DCSM模块的相关设置和操作。
