## 使用说明
- 本例展示了如何使用dcc模块对目标时钟进行频率测量
- 使用外部晶振作为参考，测量内部时钟OSC2的时钟的频率
- result为0代表内部时钟频率在正常范围内，result为1代表内部时钟频率偏差较大
