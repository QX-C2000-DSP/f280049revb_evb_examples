## 使用说明
- 本例展示了如何使用dcc模块的单次测量模式
- 使用外部晶振作为参考来验证PLL输出时钟频率，外部晶振频率10M，PLL输出时钟频率100M
- result为0代表校验成功，result为1代表校验失败
